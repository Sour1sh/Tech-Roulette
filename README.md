# CampusGig: Campus Part-Time Opportunity Hub

**Hackathon Problem 12.** A platform where students can discover, filter and apply for **verified** part-time jobs, tutoring gigs, events and campus jobs.

## Live website
https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPO-NAME/

## The problem
Students struggle to find legitimate part-time, tutoring, event and campus opportunities. Listings are scattered across chat groups and notice boards, and scams are hard to spot.

## Our solution
- **Verified listings:** only checked posters appear as verified.
- **Search and filters:** by keyword, category, location and verified status.
- **One-step apply:** a short form with a confirmation message.
- **Scam flags:** unverified or fee-charging listings are flagged and cannot take applications.

## Tech stack
HTML, CSS and vanilla JavaScript. No backend or build step. Sample data is stored in `js/app.js`.

## Run locally
Open `index.html` in any browser.
